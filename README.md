# Ask Gemini 🤖

An AI-powered question-answering website built using HTML, CSS, JavaScript, Node.js, Express, and the Gemini API.

## 🚀 Live Demo

[Open Ask Gemini Website](https://ask-gemini-9swq.onrender.com/)

## ✨ Features
- Ask questions and receive AI-generated answers.
- Simple, responsive user interface.
- Node.js and Express backend.
- Gemini API integration.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Gemini API
